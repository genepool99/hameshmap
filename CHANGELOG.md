# Changelog

## 0.1.0

- Sidebar map of MeshCore contacts with an advertised position.
- Marker clusters with counts; nodes at the same place are spread out when zoomed in.
- Node list with search, sorting and filters by type, age and position.
- Node clocks that are ahead or not set are marked and not used for freshness.
- Node details: type, last advert, last heard, SNR, hop count, stored route.
- Options: MeshCore entries, stale threshold, refresh interval, map tiles.
